The education site is now **OpenJCockpit Docs**: one place for learning OpenJCockpit and for looking
things up.

{/* truncate */}

## What changed

- **Learn** (`/learn`) holds the tutorials, concepts, workshops and video scripts. It was `/docs`
  before. Old `/docs/...` links redirect to the new address.
- **Reference** (`/reference`) is the product documentation: architecture, workflows, governance,
  integrations, operations and configuration. It is written in the
  [OpenJCockpit repository](https://github.com/OpenJCockpit/OpenJCockpit/tree/main/docs/readme) and
  published here automatically, so there is one source of truth. Every reference page links back to
  the file you would edit.
- The site moved to a new address: `https://openjcockpit.github.io/OpenJCockpit-docs/`. Update any
  bookmarks.

## Where to start

New to OpenJCockpit? Start with [What is OpenJCockpit?](/learn/intro). Looking for a flag, a runbook
or a policy detail? Open the [reference](/reference).
